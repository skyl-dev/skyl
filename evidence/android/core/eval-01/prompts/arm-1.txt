Build the order history screen for an Android shopping app.

The screen shows a user's past orders, newest first. Each row shows the order number, the date it
was placed, the total, and its current status. Tapping a row opens the order detail screen.

There is a filter at the top with three choices — All, Delivered, Cancelled — and a search field
that filters by order number as the user types.

Orders come from `GET /api/orders`, which returns JSON. The user can be signed out at any time,
including by the server rejecting a request.

Use Kotlin and Jetpack Compose. Write the files you would actually write.
